# Reddit Ban Checker

> Free viral tool to check if your Reddit post will get banned

## Stack

- Next.js 15
- TypeScript
- Tailwind CSS
- Gemini AI

## Setup

```bash
npm install
cp .env.local.example .env.local
# Add GOOGLE_GEMINI_API_KEY
npm run dev
```

## Deploy

Deploy to Vercel and point subdomain `check.unbannnable.com` to it.

## Purpose

Drive traffic to main Unbannnable app through viral free tool.
